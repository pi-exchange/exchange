# Диаграммы лабораторной № 2

Семь моделей соответствуют разделу 4 [документа требований](../01-requirements.md). `.puml` — редактируемые исходники, `.png` — экспорты для просмотра и сдачи. Будущие функции выделены пометкой «план».

Использован официальный PlantUML **1.2026.9** (Java 17) и Graphviz **14.0.5**. SHA-256 `plantuml.jar`: `aa4a1d06f8911c4b842beff4828dd955be431692b631a312d04c0e9fab9581de`.

Скачать `plantuml.jar` из [официального выпуска](https://github.com/plantuml/plantuml/releases/tag/v1.2026.9), установить Graphviz и запускать из корня **pi-exchange/exchange**:

```sh
java "-Djava.awt.headless=true" -jar /path/to/plantuml.jar -charset UTF-8 -failfast2 -tpng "docs/diagrams/*.puml"
python scripts/check-lab2.py
```

В Windows вместо `/path/to/plantuml.jar` указать путь к локальному JAR. Если Graphviz отсутствует в PATH, задать `GRAPHVIZ_DOT` полным путём к `dot.exe`. JAR и установленный Graphviz в репозиторий не включаются. Диаграммы строятся локально; содержимое не отправляется на внешние серверы рендеринга.

После правки `.puml` повторно создать соответствующий PNG и проверить его визуально: подписи, кратности, отсутствие обрезанного текста. `check-lab2.py` проверяет комплектность, ссылки, номера и совпадение таблиц; семантическое ревью и визуальную проверку он не заменяет.
